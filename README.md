# Weather Forecast Application 🌦️

A beautiful, responsive weather application that displays current weather conditions with dynamic backgrounds, detailed weather data, and theme-based styling.

## Features ✨
 -** Link :- "https://weather-forecast-akm-18.onrender.com/"
- **Real-time Weather Data**: Get current weather conditions for any city worldwide
- **Dynamic Backgrounds**: Automatically changes based on weather conditions
- **Detailed Weather Info**:
  - Temperature (current and feels-like)
  - Humidity, Wind speed, Pressure
  - Visibility, UV Index, Gust speed
  - Weather condition with icons
- **Responsive Design**: Works perfectly on all device sizes
- **Visual Themes**: Color schemes adapt to different weather conditions
- **Local Time Display**: Shows local time of the searched location
- **Interactive UI**: Hover effects and smooth transitions

- **API**:

  - Create React App (or Vite)
